An LLM inference engine, written from scratch for two CPU cores.

edgeinfer runs Qwen3.5 (the hybrid Gated-DeltaNet + attention family) with its own C++ kernels, scheduler and OpenAI-compatible server. On this machine it is faster than llama.cpp and Ollama, and it powers the chat you can try below.

How it works

What had to be built

The engine

C++17 with no dependencies: the Gated DeltaNet recurrence and gated attention, tiled 4/6/8-bit weights, AVX2 integer kernels, its own thread pool. Matches Hugging Face transformers to KL ≈ 1e-7.

Quantization

Activation-aware calibration, a per-layer sensitivity scan and mixed precision, so 4-bit files keep llama.cpp Q4_K_M quality. The 4-bit kernel sums whole 256-value blocks in integers.

Speculative decoding

The model's own multi-token-prediction head drafts the next token; one batched pass verifies it. A 32K-token draft vocabulary keeps drafting cheap. Up to +45% on 4B, identical output.

Caching a recurrent model

DeltaNet state cannot be rewound, so the scheduler snapshots it at chat-turn boundaries and on disk; follow-up turns and restarts skip re-reading the conversation.

Serving

OpenAI-compatible API with streaming and tool calls, continuous batching, Prometheus metrics, idle unload. Benchmarked against llama.cpp, Ollama, llama-cpp-python and transformers.

Data Desk

A tool-using agent over SQLite: read-only SQL plus hybrid search (BM25 and multilingual embeddings with rank fusion). Login, per-account quotas, conversation history, feedback.
